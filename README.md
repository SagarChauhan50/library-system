# 📚 Library Management System

A web-based Library Management System built with **Python**, **Flask**, and **SQLite**. This application allows users to register, log in, browse a book catalog, borrow books, and manage their returns seamlessly. It is fully responsive and deployed live.

🔗 **Live Demo:** [https://library-system-1-f4zp.onrender.com/](https://library-system-1-f4zp.onrender.com/)

---

## 🚀 Core Features
* **User Authentication:** Secure user registration and login system with session management.
* **Book Catalog:** Browse available books with details on authors and stock levels.
* **Borrowing System:** Users can borrow available books, which automatically updates stock and records the transaction.
* **Return Management:** Users can view their active borrowed books on their dashboard and return them with a single click.
* **Admin View:** Built-in endpoint (`/admin/view-data`) to monitor all registered users and active borrowing transactions.

---

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Database:** SQLite
* **Frontend:** HTML5, CSS3
* **Deployment:** Render
